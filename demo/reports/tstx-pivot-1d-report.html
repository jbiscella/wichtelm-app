Strategy: Daily Pivot Levels

Enter long on a break above R1 resistance

Direction: LONG

GIVEN no open position
WHEN price_crosses_above_pivot(R1)
THEN enter LONG

Stop: entry_price * (1 - stop_loss_pct / 100)
Take: entry_price * (1 + take_profit_pct / 100)

Exit long when price falls back below the pivot

Direction: LONG

GIVEN an open long position
WHEN price_crosses_below_pivot(P)
THEN close the position

Exit short when price reclaims the pivot

THEN close the position
